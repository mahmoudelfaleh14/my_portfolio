# Mahmoud Salah El-Faleh — Cinematic Flutter Portfolio

A responsive single-page portfolio built around the approved visual direction:
realistic cinematic / tactical / industrial / gritty, with a distressed skull motif, black + dirty-white + blood-red palette, dossier layouts, and Flutter-focused content.

## Run
Open `index.html` directly, or serve the folder with any static server.

Example:
```bash
npx serve .
```

## Structure
- `index.html` — full portfolio
- `styles.css` — design system + responsive UI
- `script.js` — navigation and scroll interactions
